Video တစ်ခု ထည့်လိုက်ရုံနဲ့ မြန်မာ အသံဇာတ်ကြောင်း + subtitle ပါတဲ့ recap video အဖြစ် ပြောင်းပေးတဲ့ app
⬇️ Android ဒေါင်းရန်
ဒေါင်းပြီးရင် install လုပ်ပါ — "Unknown apps" ခွင့်ပြုချက် တောင်းရင် ခွင့်ပြုပေးပါ။ နောက်ဆုံးထွက် version ကို ဒီကပဲ အမြဲ ရနိုင်ပါတယ်။
🎬 အလိုအလျောက် pipeline — video ကနေ စာတမ်း → ဇာတ်ညွှန်း → အသံ → video အပြည့်
🎙️ AI အသံ ၃၀ မျိုး — Gemini voice တွေ ကြိုက်ရာ ရွေးနိုင်
💬 Subtitle + ဘာသာပြန် — မြန်မာ အပါအဝင် ဘာသာစကား ၁၁ မျိုး
🛡️ Copyright layer — mirror, zoom, speed, pitch အလိုအလျောက် ညှိပြီး
⚙️ Setting အကုန် — ကိုယ်ကြိုက် ညှိနိုင်၊ live preview နဲ့
🔑 ကိုယ့် Gemini key နဲ့ သုံးတာ — server မလို၊ ဖုန်းထဲမှာပဲ အကုန် လုပ်တယ်

သုံးနည်း
